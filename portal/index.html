Cuatro pasos

Del ZIP al GLB riggeado, todo desde el navegador.

  1. Descarga y descomprime

    Pulsa el botón y extrae trellis-autorig-colab.zip: dentro están el cuaderno y una guía (LEEME.md).

  2. Súbelo a Colab

    En colab.research.google.com: Archivo → Subir cuaderno. O usa directamente el botón «Abrir en Colab».

  3. Elige GPU y ejecuta

    Entorno de ejecución → Cambiar tipo → GPU y «Ejecutar todas». La primera instalación puede tardar 15–25 min.

  4. Genera tu GLB

    Abre el enlace de Gradio, sube una imagen, marca Enable Auto-Rigging, pulsa Extract GLB y descárgalo.

Qué hace el cuaderno

Automatiza la parte difícil: un entorno compatible con TRELLIS, la compilación para tu GPU y Blender en modo headless.

Entorno aislado

Crea Python 3.10 con PyTorch 2.4 y CUDA 12.1 aparte. No toca el entorno de Colab, que hoy trae Python 3.13 y CUDA 13.

TRELLIS: imagen a 3D

Usa el pipeline oficial de Microsoft TRELLIS (commit fijado) y su exportación a GLB con textura.

Auto-rig con Blender 4.5 LTS

Armature humanoide aproximada con pesos automáticos, exportada como GLB con skin y materiales.

Versiones fijadas

Dependencias con lockfile, Blender verificado con SHA-256 y una comprobación final de GPU e importaciones antes de arrancar.

Contenido del ZIP

Una carpeta trellis-autorig-colab/ con dos archivos. El cuaderno descarga el resto (app, scripts, TRELLIS y Blender) desde GitHub al ejecutarse.

  • TRELLIS_AutoRig_Colab.ipynb el cuaderno de Colab
  • LEEME.md guía de uso y solución de problemas

Requisitos y límites

Conviene saberlo antes de empezar.

Necesitas

  • Una cuenta de Google para usar Colab.
  • Una GPU NVIDIA con unos 16 GB. La T4 gratuita (15 GB) va justa; L4, A100 o H100 van mejor.
  • Paciencia la primera vez: 15–25 minutos de instalación, más la descarga de los pesos del modelo.

Ten en cuenta

  • GPU Blackwell («G4») no compatible con PyTorch 2.4 / CUDA 12.1.
  • El rig es una plantilla geométrica, no detecta articulaciones: es un punto de partida para personajes verticales.
  • El enlace público de Gradio lo puede usar cualquiera que lo tenga mientras la app esté activa.
  • Colab es efímero: descarga el GLB antes de parar la sesión.

¿Algo falla? La instalación fija versiones, pero Colab cambia su entorno a menudo. Abre un issue en GitHub con el registro que el cuaderno guarda en /content/setup_logs/.
